Five read-only reviews (API/security, sources/alerts, scoring/resume, web UI, Windows app).
Top items were spot-checked against the live database and code.

**Status (2026-10-12): all four batches fixed.** Batch 1 `5a84e90`, Batch 2 `cd5f6f3`,
Batch 3 `919411c`, Batch 4 `76ec1cf` plus the rebuild follow-up below. Decisions 1–7

## Decisions needed from the user

1. Treat GitHub lists as incomplete by default (no auto-closing from them)? — recommended yes
2. Retry failed Discord alerts, or accept they are lost? — recommended retry
3. Same title at a different location: separate alert? — recommended yes
4. Graduation-month near-miss and plain "Analyst" titles for final-year students: hide, or show with a review note? — recommended review note
5. Bank internships with no division named (classified IB only by employer): show in resume-matched view? — recommended show only as "unclassified", not as an IB match
6. `s` on an already-tracked job: do nothing, or open the job? — recommended do nothing + toast
7. Should "Clear all" also clear the resume-match categories? — recommended yes
